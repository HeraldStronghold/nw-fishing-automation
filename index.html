FAQ

Questions Before You Cast

Everything you need to know about running nw-fishing-automation safely.

Does this bot inject into the game or read memory?
No. nw-fishing-automation is fully pixel-based. It captures the screen, recognises HUD elements and sends synthetic input. There is no DLL injection, no process hooking and no memory reading, which keeps it far outside the way traditional cheats operate.
Which resolutions and display modes are supported?
It works in borderless windowed and fullscreen modes on Windows 10 and 11. Profiles ship for 1920×1080, 2560×1440 and 3840×2160, and you can calibrate a custom resolution in a few clicks if yours differs.
Can I use my PC while the bot is fishing?
Yes, as long as the New World window stays visible and unobstructed — the bot needs to see the HUD. Borderless windowed mode is recommended if you plan to alt-tab, since exclusive fullscreen can pause rendering.
Is it really free and open source?
Completely. The full source is published, the build is free to download, and updates are pushed regularly. No accounts, no subscriptions and no paywalled modules — just download, run and fish.
